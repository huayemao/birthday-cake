Setahun yang lalu, saya membina aplikasi web [https://www.birthday-cake.online/](https://www.birthday-cake.online/). Namun saya akui, untuk tempoh yang lama pengesanan bunyi tiupannya tidak cukup tepat untuk mengasingkan bunyi tiupan daripada bunyi lain. Dalam majlis hari jadi sebenar, suasana sukar dikawal kerana penuh dengan gelak tawa dan bunyi latar. Selalunya sebaik sahaja kek disediakan, lilin terus terpadam akibat kebisingan sekeliling, ditambah pula dengan perbezaan kepekaan mikrofon antara peranti.

Sebelum ini saya mencuba beberapa langkah sementara seperti butang "Kunci" dan peluncur kepekaan mikrofon, tetapi ia tidak menyelesaikan punca sebenar masalah tersebut.

![Paparan kek dalam birthday-cake.online menyokong kunci mikrofon bagi mengelakkan lilin terpadam secara tidak sengaja](https://huayemao.run/api/files/64ad60dc2fb66d47.webp)

Dalam versi terbaharu, masalah ini akhirnya diselesaikan sepenuhnya. Kini aplikasi dapat mengenal pasti ciri akustik aliran tiupan manusia dengan tepat sambil menapis sebahagian besar bunyi bising persekitaran. Dalam ujian sebenar—termasuk di dalam kereta api bawah tanah dan kantin Universiti Yunnan yang sibuk—hanya dengan menurunkan sedikit kepekaan, aplikasi berfungsi dengan amat stabil.

![Pelarasan kepekaan mikrofon semasa menghias kek hari jadi maya di birthday-cake.online](https://huayemao.run/api/files/fc05e31fbc6fb544.png)

Pendekatan yang saya gunakan kedengaran ringkas tetapi terbukti sangat berkesan: saya merakam beberapa klip audio tiupan sebenar dan memberikannya kepada Code Agent untuk menganalisis ciri domain frekuensi dan masa, kemudian menulis semula algoritma pengesanan berdasarkan data sebenar tersebut. Dahulu saya hanya menerangkan ciri tiupan menggunakan teks kepada AI sehingga hasilnya tidak konsisten merentas peranti. Kali ini saya menulisnya semula dalam Antigravity IDE menggunakan model Gemini Neon terbaharu—jelas sekali konteks berkualiti tinggi dan sampel audio sebenar memberikan hasil yang jauh lebih mantap.

Semasa penyahpepijatan di komputer riba Windows, saya mendapati tiupan langsung tidak dikesan manakala suara percakapan pula dikesan. Rupa-rupanya ciri "Audio Enhancements" Windows menganggap tiupan sebagai bunyi angin dan menapisnya sepenuhnya. Jika mengalami masalah sama pada Windows, pergi ke **Settings → System → Sound → Properties (Microphone Array) → Advanced** dan matikan **Audio Enhancements**.

![Mematikan Audio Enhancements mikrofon pada Windows untuk menyahdayakan penapisan bunyi angin](https://huayemao.run/api/files/9376f8328df3534c.webp)

Selain menulis semula algoritma teras, kemas kini ini turut memperkenalkan dua butiran penting:

1. **Penentukuran Sampel Tiupan**: pengguna boleh merakam sampel ringkas dalam persekitaran semasa agar aplikasi menganalisis bunyi latar dan corak tiupan secara dinamik.
    ![Ciri penentukuran sampel tiupan dalam birthday-cake.online](https://huayemao.run/api/files/d247ef9715a40b1f.png)
2. **Visualisasi Gelombang Bunyi Masa Nyata**: paparan kek kini memaparkan gelombang bunyi persekitaran secara langsung supaya pengguna dapat melihat dengan jelas bahawa sistem mendengar bunyi tetapi mengenalinya bukan sebagai tiupan.
