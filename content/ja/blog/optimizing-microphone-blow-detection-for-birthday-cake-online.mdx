1年前、私は [https://www.birthday-cake.online/](https://www.birthday-cake.online/) というWebアプリを開発しました。しかし正直なところ、長い間「息を吹く音」の認識精度はお世辞にも高いとは言えず、他の音を無視して吹く音だけを正確に判別することができませんでした。実際の誕生日パーティーの現場は環境をコントロールするのが難しく、みんなの歓声や笑い声、生活音などさまざまなノイズが飛び交います。せっかくケーキとろうそくを準備して本番シーンに入った瞬間に、周囲の騒音で誤検知され、ろうそくが勝手に「吹き消されて」しまうことがよくありました。さらにデバイスごとにマイク感度が大きく異なり、わずかな物音で消えてしまう端末もあれば、どれだけ強く吹いても反応しない端末もあり、体験が大きく損なわれていました。

これまでも対症療法はいくつか試しました。ケーキを配置したあとにマイク検知を一時停止し、主役が本当に吹く直前に解除できる「ロック」ボタンを追加したり、マイク感度のスライダーを用意したりしましたが、根本的な解決には至らず、実際の使い心地はまだ不安定なままでした。

![birthday-cake.online のケーキシーンではマイク検知をロックして誤消灯を防止できます](https://huayemao.run/api/files/64ad60dc2fb66d47.webp)

そして今回の最新アップデートで、ようやくこの問題を根本から解決できました。現在のアプリは息を吹きかける気流特有の音響特徴を正確に捉え、それ以外の雑音を最大限無視できます。適切な感度に設定しておけば、周囲のノイズで誤って消える心配はなく、主役が息を吹きかければスムーズに火が消えます。実際に地下鉄の中や、雲南大学の賑やかな食堂でテストしたところ、感度を少し下げるだけで環境音に邪魔されず期待どおり安定して動作しました。

![バーチャル誕生日ケーキアプリ birthday-cake.online のマイク感度設定画面](https://huayemao.run/api/files/fc05e31fbc6fb544.png)

私が取った解決方法は一見とてもシンプルですが、驚くほど効果的でした。実際の「息を吹く音声」をいくつか録音し、それを Code Agent に渡して周波数領域・時間領域の特徴を解析させ、そのデータを基準に音声認識アルゴリズムを全面的に書き直したのです。初期開発時は言葉だけで AI に吹く音の特徴を説明してアルゴリズムを書かせていたため、何度調整してもハードウェアごとのばらつきが収まりませんでした。今回は Antigravity IDE 上で最新の Gemini Neon モデルを使って書き直しました。以前のモデルで同じ成果が出せたかは分かりませんが、「どれほど優秀な“人材”であっても、質の高いコンテキストと生の素材を与えることが不可欠だ」と強く実感しました。実際の音声サンプルを渡さず自然言語の説明だけに頼っていては、AI の理解にも限界があります。

もちろん、デバッグは順調なことばかりではありませんでした。新しいアルゴリズムを書き終えて自分のノートPCで最初にテストしたところ、どれだけ吹いても全く反応せず、かえって話し声のほうが検知されてしまったのです。Windows 標準のボイスレコーダーで録音して確認してみると、そもそもマイクが息を吹く音を一切拾っていませんでした。原因は Windows の「オーディオの強化」機能で、息を吹く音を風切り音ノイズとみなして丸ごとカットしていたのです。Windows で同様の現象が起きた場合は、**設定 → システム → サウンド → プロパティ（マイク配列）→ 詳細設定** から【オーディオの強化】をオフにしてみてください。

![Windows でマイクのオーディオ強化をオフにしてノイズ抑制を解除する設定画面](https://huayemao.run/api/files/9376f8328df3534c.webp)

コアの検知アルゴリズム刷新に加え、今回のアップデートでは2つの重要な機能も追加しました。

1. **吹き消し音声キャリブレーション**：設定画面でその場の環境音を少し録音することで、アプリが現在の環境ノイズと有効な吹く音の特徴を動的に解析し、デバイスと環境に合わせて最適にキャリブレーションします。
    ![birthday-cake.online の吹き消しサンプリング・キャリブレーション機能](https://huayemao.run/api/files/d247ef9715a40b1f.png)
2. **リアルタイム音波ビジュアライザー**：ケーキシーン内に環境音の波形をリアルタイム表示するようにしました。会話やバースデーソング、拍手、微弱な気流などに合わせて波形が動くため、「システムは音を拾っているが、息を吹く音ではないと判断している」という状態がひと目で分かるようになりました。
